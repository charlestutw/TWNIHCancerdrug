# 健保第九節抗癌藥物速查表 · Chrome 擴充功能

側邊欄常駐的第九節官方條文速查，離線可用、自動更新。

## 安裝（約 1 分鐘）

1. 解壓縮本資料夾到一個**固定位置**（之後不要刪除或搬動，Chrome 會持續從這裡讀取）
2. Chrome 網址列輸入 `chrome://extensions`
3. 右上角開啟 **開發人員模式**
4. 按左上角 **載入未封裝項目**，選擇本資料夾（含 `manifest.json` 那一層）
5. 完成。建議按工具列的拼圖圖示，把本擴充功能 **釘選** 到工具列

## 使用

- **點工具列圖示** → 在右側開啟側邊欄，可邊看病歷邊查
- **在新分頁開啟** → 需要大版面時切換成全頁模式
- **全文搜尋 / 精確搜尋** → 切換搜尋範圍（全部欄位 vs 僅藥名與商品名）
- **檢查更新** → 立即向雲端抓最新資料

## 資料與更新

- 內建 `data.json`，**完全離線也能用**
- 每次開啟會在背景比對雲端版本，較新時自動更新並快取
- 雲端來源：`raw.githubusercontent.com/charlestutw/TWNIHCancerdrug/main/nhi-ch9-data.json`
- 標題列會顯示目前資料版本與來源（內建／雲端快取／雲端最新）

## 權限說明

| 權限 | 用途 |
|---|---|
| `storage` | 快取雲端下載的資料 |
| `sidePanel` | 以側邊欄形式顯示 |
| `raw.githubusercontent.com` | 取得最新條文資料 |

**不會**讀取你瀏覽的任何網頁內容，也不會蒐集或外傳任何資料。

## 需求

Chrome 114 以上（側邊欄 API）。部分醫院託管的 Chrome 可能停用開發人員模式，若「載入未封裝項目」為灰色，需由資訊單位協助。

## 更新擴充功能本身

條文資料會自動更新，不需重裝。只有介面或程式邏輯改版時才需要：覆蓋資料夾後，到 `chrome://extensions` 按本擴充功能的**重新載入**圖示。
